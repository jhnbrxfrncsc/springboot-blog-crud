# Spring Boot Blog API (Mini Project)

A Spring Boot blog API with CRUD, pagination, search, JWT authentication, and PostgreSQL, built using Spring Data JPA and Lombok.

---

## Features

- User and Post CRUD operations
- Offset pagination and search functionality
- JWT-based authentication with Spring Security
- Validation logic via Validator classes
- Layered architecture with Service & Repository
- PostgreSQL database integration

---
